# 🍔 Food Delivery Service System (C++)

A **console-based Food Delivery Management System** developed using **C++** and **Object-Oriented Programming (OOP)** principles.

## 📌 Project Overview
The Food Delivery Service System allows users to:
- Select food categories
- Choose restaurants
- Add items with different sizes to a cart
- Generate a final bill

The project simulates the basic workflow of a real-world food delivery platform in a **simple and structured console environment**.

---

## 🧠 OOP Concepts Used
- **Classes & Objects** – Modeling real-world entities such as `User`, `Cart`, and `Restaurant`
- **Inheritance** – Food categories inherit from the abstract `Restaurant` class
- **Polymorphism** – `show_menu()` is overridden and accessed via base class pointers
- **Abstraction** – Implemented using pure virtual functions
- **Encapsulation** – Data members protected and accessed through class methods
- **Dynamic Memory Allocation** – Runtime object creation using `Restaurant*`
- **STL (Vectors)** – Used for cart management (items, sizes, prices)
